## Pick your runtime

The same chain runs everywhere. What changes is which entry point you import and how your runtime hands you a request.

<Tabs items={["Deno", "Node", "Bun", "Cloudflare Workers"]}>
  <Tabs.Tab>

```ts filename="app.ts"
import {
  Chain,
  Resource,
} from "@drashland/drash/modules/chains/RequestChain/mod.native.js";

class Home extends Resource {
  paths = ["/"];

  GET(request: Request) {
    return new Response("Hello from Home.GET()!");
  }
}

const chain = Chain.builder().resources(Home).build();

Deno.serve({ hostname: "localhost", port: 1447 }, (request: Request) => {
  return chain
    .handle<Response>(request)
    .catch(() => new Response("Internal Server Error", { status: 500 }));
});
```

Deno has a global `URLPattern`, so it uses the **native** entry point. [Full guide →](/quickstart/deno)

```js filename="app.js"
import {
  Chain,
  Resource,
} from "@drashland/drash/modules/chains/RequestChain/mod.polyfill.js";
import { createServer } from "node:http";

class Home extends Resource {
  paths = ["/"];

  GET(context) {
    context.response.end("Hello from Home.GET()!");
  }
}

const chain = Chain.builder().resources(Home).build();

createServer((request, response) => {
  // The chain only requires a readable `url` and `method`. `url` must be
  // absolute — `request.url` from node:http is path-only.
  const context = {
    url: `http://localhost:1447${request.url}`,
    method: request.method,
    request,
    response,
  };

  return chain.handle(context).catch(() => {
    response.statusCode = 500;
    response.end("Internal Server Error");
  });
}).listen(1447, "localhost");
```

Node passes a **context object** rather than a Web `Request`, and uses the **polyfill** entry point. [Full guide →](/quickstart/node)

import {

} from "@drashland/drash/modules/chains/RequestChain/mod.polyfill.js";

Bun gives you Web `Request`/`Response`, but uses the **polyfill** entry point. [Full guide →](/quickstart/bun)

```js filename="app.js"
import {
  Chain,
  Resource,
} from "@drashland/drash/modules/chains/RequestChain/mod.native.js";

class Home extends Resource {
  paths = ["/"];

  GET(request) {
    return new Response("Hello from Home.GET()!");
  }
}

// Built once per isolate, reused across requests.
const chain = Chain.builder().resources(Home).build();

export default {
  fetch(request, _bindings) {
    return chain
      .handle(request)
      .catch(() => new Response("Internal Server Error", { status: 500 }));
  },
};
```

Workers have a global `URLPattern`, so they use the **native** entry point. Keep config values as module-local `const`s — `workerd` rejects non-function named exports. [Full guide →](/quickstart/cloudflare-workers)

The two entry points differ only in which `URLPattern` implementation they use. See [Native vs. polyfill](/concepts/native-vs-polyfill).

## Install

```bash
npm install @drashland/drash
```

Deno can import it over HTTP without installing anything:

```ts
import {
  Chain,
  Resource,
} from "https://esm.sh/@drashland/drash/modules/chains/RequestChain/mod.native.js";
```
