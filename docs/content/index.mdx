## Works With

Drash targets the runtime you already have. The only thing that changes between
them is the entry point you import and how your server hands it a
request.

| Runtime            | Minimum Version         | Web `Request` / `Response` at the server boundary |
| ------------------ | --------------- | ------------------------------------------------- |
| Node               | 20.x            | No — `node:http` gives you a context object        |
| Deno               | 1.x             | Yes — `Deno.serve` passes a `Request`              |
| Bun                | 1.x             | Yes — `Bun.serve` passes a `Request`               |
| Cloudflare Workers | Current runtime | Yes — the Worker `fetch` handler passes a `Request` |
