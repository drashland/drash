# Releases

Notes for each published version, newest first. Every entry lists what changed,
what broke, and what you have to do about it.

| Version | Date | Summary |
| ------- | ---- | ------- |
| [v3.0.0](/releases/v3-0-0) | 25 August 2026 | The first stable v3. A complete rewrite: runtime-agnostic, not an HTTP server wrapper, built on Web Standards. |

Versions before v3.0.0 were previews and betas. They are on
[GitHub Releases](https://github.com/drashland/drash/releases) and are not
documented here — the API moved between them, and none of it is what v3.0.0
ships.

## Versioning

Drash follows [semantic versioning](https://semver.org). A major version is the
only place a breaking change lands, which is why v2 code does not run on v3 and
why there is no compatibility layer between them.
