# Quickstart

Drash is not an HTTP server wrapper. You build an application &mdash; a chain of handlers under the hood &mdash; and pass a request into it from whatever server your runtime already gives you (`Deno.serve()`, `Bun.serve()`, etc.) &mdash; so the setup differs only in how your runtime hands you that request.

Pick your runtime below, or walk through the build one step at a time.

Each page has a complete, runnable application and notes specific to that runtime.

| Runtime            | `URLPattern`                   | Request shape              | Entry point       |
| ------------------ | ------------------------------ | -------------------------- | ----------------- |
| Deno               | Global &mdash; used directly         | Web `Request` / `Response` | `http.native.js`   |
| Node               | Varies by version &mdash; polyfilled | Context object you build   | `http.polyfill.js` |
| Bun                | Not dependable &mdash; polyfilled    | Web `Request` / `Response` | `http.polyfill.js` |
| Cloudflare Workers | Global &mdash; used directly         | Web `Request` / `Response` | `http.native.js`   |

The two entry points differ only in which `URLPattern` implementation they use &mdash; see [About > Concepts > Native vs. Polyfill](/about/concepts/native-vs-polyfill) to learn more.
