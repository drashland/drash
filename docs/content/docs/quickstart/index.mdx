# Quickstart

Drash ships no server. You build a chain of handlers and pass a request into `chain.handle()` from whatever server your runtime already gives you — so the setup differs only in how your runtime hands you that request.

Pick your runtime below, or walk through the build one step at a time.

Each page has a complete, runnable application and the notes specific to that runtime.

| Runtime            | Entry point       | Request shape                       |
| ------------------ | ----------------- | ----------------------------------- |
| Deno               | `mod.native.js`   | Web `Request` / `Response`          |
| Node               | `mod.polyfill.js` | Context object you build            |
| Bun                | `mod.polyfill.js` | Web `Request` / `Response`          |
| Cloudflare Workers | `mod.native.js`   | Web `Request` / `Response`          |

The two entry points differ only in which `URLPattern` implementation they use — see [Native vs. Polyfill](/docs/concepts/native-vs-polyfill).

## Before you start

If you do not have a runtime installed yet, or have never stood up an HTTP server in it, read [Prerequisites](/docs/getting-started/prerequisites) first.
