# Introduction

Welcome! We're glad you're here!

Want to skip ahead and build something? Head straight to the [quickstart](/docs/quickstart) pages.

## What Is Drash?

Drash is a micro web framework for JavaScript. It is strongly typed, runtime-agnostic, and built on Web Standards. The result is a framework that stays out of the way: readable by people, actionable by agents, and acomptaible with the web wherever it runs. Use it in Deno, Node, Bun, Cloudflare Workers, and any other environment that can run JavaScript.

For the ideas behind it, read [Framework](/docs/concepts/framework) and [Chains](/docs/concepts/chains).

## Features

- Ships with zero dependencies <sup>1</sup>
- Runtime agnostic <sup>2</sup>
- Extensively documented so you can develop with confidence
- Hella typed so you can use it with your TypeScript codebase
- Built to work as an [ECMAScript Module](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules) and a [CommonJS Module](https://nodejs.org/modules.html)
- Dynamic paths (e.g., `/users/:id`) <sup>3</sup>
