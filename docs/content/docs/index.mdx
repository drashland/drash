# Documentation

Drash ships no server. You build a chain of handlers and pass a request into `chain.handle()` from whatever server your runtime already gives you. These pages cover how to do that, why it is built that way, and what every piece does.

New here? Start with the [introduction](/docs/getting-started/introduction), then build something with the [step-by-step guide](/docs/quickstart/step-by-step-guide).
