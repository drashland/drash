# StatusName

```ts
import { StatusName } from "@drashland/drash/core/http/response/StatusName.js";

StatusName.NotFound; // "NotFound"
```

The status names themselves, each mapped to its own string:

```ts
const StatusName = {
  Continue: "Continue",
  SwitchingProtocols: "SwitchingProtocols",
  // ... 60 more
} as const;
```

62 entries. Because it is declared `as const`, it is what makes
[`ResponseStatusName`](/reference/core/types#responsestatusname) a union of string literals
rather than plain `string` &mdash; which in turn is what keys
[`Status`](/reference/core/http/response/status),
[`StatusCode`](/reference/core/http/response/status-code), and
[`StatusDescription`](/reference/core/http/response/status-description), so all four stay
in step.

Not re-exported from the HTTP module; see
[Status](/reference/core/http/response/status#not-re-exported).
