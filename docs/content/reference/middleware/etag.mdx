# ETag

Adds `ETag` and `Last-Modified` headers, and answers `304 Not Modified` when a request's `If-None-Match` matches.

```ts
import { ETag } from "@drashland/drash/modules/middleware/ETag/mod.js";

const group = Resource
  .group()
  .middleware(ETag())
  .resources(Users)
  .build();
```

## Options

| Option            | Type      | Default | Notes                                    |
| ----------------- | --------- | ------- | ---------------------------------------- |
| `etag_max_length` | `number`  | `27`    | Characters of the generated hash to keep |
| `weak`            | `boolean` | `false` | Emit a weak validator (`W/"..."`)        |

### `weak`

A weak ETag (`W/"abc"`) tells caches two representations are semantically equivalent even if the bytes differ. Set it when byte-for-byte equality is not what you want compared.

```ts
ETag({ weak: true });
```

## Behavior

| Request                                  | Result                                    |
| ---------------------------------------- | ----------------------------------------- |
| No `If-None-Match`                       | Response gains `ETag` and `Last-Modified` |
| `If-None-Match` matches the current ETag | `304 Not Modified`, empty body            |
| `If-None-Match` does not match           | Full response with a fresh `ETag`         |

An empty response body still gets an ETag — the hash of empty content is stable, so repeat requests for an empty resource still revalidate correctly.

| Export           | What it is                                      |
