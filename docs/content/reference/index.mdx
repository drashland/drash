# Reference

Drash is split into three codebases, and this reference follows that split. Imports flow one direction — Modules → Standard → Core — which is what keeps each layer independently useful. [Framework](/docs/concepts/framework) covers the reasoning; these pages cover the API.

## The three layers

| Layer                                          | What it holds                                                                                  |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [Core](/reference/core/http-error)             | Types, interfaces, and classes with minimal implementation — the lowest-level APIs. Imports nothing else. |
| [Standard](/reference/standard/resource-group) | Standalone library code, in the spirit of Deno's or Go's standard library. Imports only Core.     |
| [Modules](/reference/modules/http/chain)            | The pieces that do the work, such as the Request Chain. Imports Standard and Core.               |
