# Reference

Drash is split into three codebases, and this reference follows that split. Imports flow one direction &mdash; Modules → Standard → Core &mdash; which is what keeps each layer independently useful. [Framework](/about/concepts/framework) covers the reasoning; these pages cover the API.

## The Three Layers

| Layer                              | What it holds                                                                                             | Imports        |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------- | -------------- |
| [Core](/reference/core)            | Types, interfaces, enums, `HTTPError`, and the base `Resource`. The lowest-level APIs.                     | Nothing        |
| [Standard](/reference/standard)    | Standalone library code, in the spirit of Deno's or Go's standard library &mdash; handlers, middleware, loggers. | Core           |
| [Modules](/reference/modules)      | The pieces that do the work: the HTTP module, the pre-built middleware, the builders.                        | Standard, Core |

## Where to Start

Most applications only touch Modules. The two entry points &mdash; `modules/http.native.js` and `modules/http.polyfill.js` &mdash; re-export what you need from the layers below, so a normal app imports `Application`, `Resource`, `Middleware`, `ResourceGroup`, and `HTTPError` from one specifier.

| If you want to                          | Read                                                              |
| --------------------------------------- | ----------------------------------------------------------------- |
| Build and run an HTTP application        | [Application](/reference/modules/http-native)                            |
| Write a resource                         | [Resource](/reference/core/http/resource)                              |

| Attach middleware or prefixes            | [Resource groups](/reference/standard/http/resource-group)             |
| Use a pre-built middleware                 | [CORS](/reference/modules/middleware/cors) and its siblings       |
