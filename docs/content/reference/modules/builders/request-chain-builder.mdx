# RequestChainBuilder

The request chain's builder, reached through
[`Application.builder()`](/reference/modules/http-native#builder) rather than directly.

```ts
import { requestChain } from "@drashland/drash/modules/builders/RequestChainBuilder.js";
```

Returns a builder to help you create a request chain.

<Callout type="gray">
__Good to know__

The HTTP module's [`Application.builder()`](/reference/modules/http-native#builder) calls this and supplies a `URLPattern` implementation under the hood, so building an app is normally done using [`Application.builder()`](/reference/modules/http-native#builder), not `requestChain()`.
</Callout>

The returned object is typed as the `Builder` interface, which exposes exactly three methods:

| Method                       | Returns   | Notes                                              |
| ---------------------------- | --------- | -------------------------------------------------- |
| `resources(...resources)`    | `Builder` | The resource classes this chain routes to          |
| `urlPatternClass(cls)`       | `Builder` | Required — `build()` throws without it             |
| `build()`                    | `Handler` | The chain head, whose `handle()` you call          |

The `handler()` and `handlers` members inherited from `AbstractChainBuilder` are deliberately not on this interface. The request chain's handlers, and the order they run in, are decided by `build()` and are not the consumer's to change — see [Handlers](/reference/standard/handlers).

Implements [`IBuilder`](/reference/core/interfaces#ibuilderproduct) by way of
[`AbstractChainBuilder`](/reference/standard/chains/abstract-chain-builder), which it
extends. The `Builder` interface it exposes is its own — see
[the three things named `Builder`](/reference/standard/builders/builder#three-things-named-builder).
