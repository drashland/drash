# Releases

Notes for each published version, newest first. Every entry lists what changed, what broke, and other important information.

| Version | Date | Summary |
| ------- | ---- | ------- |
| [v3.0.1](/about/releases/2026-08-26-v3-0-1) | 08-26-2026 | A patch release. `queryParam()` now reads the first parameter in a query string, and Drash is published to JSR. |
| [v3.0.0](/about/releases/2026-08-25-v3-0-0) | 08-25-2026 | The first stable v3. A complete rewrite: runtime-agnostic, not an HTTP server wrapper, built on Web Standards. |

Versions before v3.0.0 were previews and betas. They are on [GitHub Releases](https://github.com/drashland/drash/releases) and are not documented here &mdash; the API moved between them, and none of it is what v3.0.0 ships.

## Versioning

Drash follows [semantic versioning](https://semver.org). A major version is the only place a breaking change lands, which is why v2 code does not run on v3 and why there is no compatibility layer between them.
